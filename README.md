# Mold Supplier Assignment Optimization

## Project Overview

This project focuses on the evaluation and assignment of mold suppliers for a procurement process. The aim is to support supplier selection by considering multiple criteria and identifying suitable supplier assignments through an optimization-based approach.

## Objective

The main objective of the project is to develop a structured supplier assignment model that considers factors such as:

- Supplier price
- Delivery time
- Production capacity
- Supplier suitability
- Assignment constraints

The project demonstrates how data-driven and optimization-based methods can be applied to procurement and supplier selection decisions.

## Methodology

The project was developed using Python and Excel-based datasets.

The general workflow includes:

1. Preparing and processing supplier and project data
2. Defining supplier evaluation criteria and project constraints
3. Evaluating alternative supplier assignments
4. Running the optimization model
5. Analyzing and exporting the optimization results
