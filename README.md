# Mold Supplier Assignment Optimization

A supplier assignment optimization project developed during my management internship in the Purchasing Department at Ototrim Panel Sanayi.

## Project Context

This project was developed during my management internship in the Purchasing Department at Ototrim Panel Sanayi.

During the internship, I worked on a mold supplier assignment project. The project focused on evaluating alternative mold suppliers and supporting the supplier selection process using quantitative criteria.

Different supplier quotations were evaluated based on criteria such as price, delivery time, capacity, and supplier-related conditions. The aim was to develop a systematic approach to support the company's mold supplier assignment decisions.

## Project Overview

The project was developed as an optimization-based decision support model for mold supplier assignment.

The model evaluates available supplier alternatives and determines an appropriate supplier assignment based on the defined decision criteria and constraints.

The project was developed in Python and the optimization model was solved using Gurobi.

## Methodology

The supplier alternatives were evaluated using criteria including:

- Price
- Delivery time
- Supplier capacity
- Supplier conditions

The optimization model was designed to support the selection of suitable mold suppliers while considering the defined project requirements and constraints.

## Project Outcome

The developed model provides a systematic and quantitative approach to mold supplier assignment.

Instead of relying only on individual supplier quotations, the model allows supplier alternatives to be evaluated within an optimization framework and provides decision support for the purchasing process.
